# Project Overview
- Tên dự án: Next Player.
- Mục đích: ứng dụng Android native viết bằng Kotlin để phát video trên thiết bị Android.
- Kiến trúc: multi-module Gradle với các thư mục chính `app`, `core`, `feature`, `specs`, `memory_bank`.
- Công nghệ chính: Kotlin, Android Gradle Plugin, Jetpack Compose, Hilt, KSP, Media3/ExoPlayer.
- Feature đang làm trong spec `001-soniox-subtitle-translation`: thêm module `core:subtitle` để xử lý live subtitle/translation bằng Soniox.
